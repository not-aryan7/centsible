# Centsible

A budgeting web app for students to track spending, set savings goals, and build better money habits.

## Team

- **Aryan Rajbhandari** — Project setup, Landing page, Dashboard
- **Dipekshya Shakya** — App routing, Login page
- **Krish Bista** — Register page

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router

## Getting Started

```bash
git clone https://github.com/not-aryan7/centsible.git
cd centsible
npm install
npm run dev
```

Then open `http://localhost:5173` in your browser.

## Current Features (Sprint 1)

- Landing page with feature overview
- User login form
- User registration form
- Dashboard with income/expense/balance summary
